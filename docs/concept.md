# Concept

## Purpose

`muse` は、esenusの活動や制作が進んでいく様子を外から見られるようにするWebサイトです。

完成したものだけでなく、試していること、途中経過、考えたこと、日々の更新、過去の記録も活動の一部として扱います。

## Position

`muse` は、作業を行うためのApplicationや、活動を管理するSystemを目的としません。活動の様子が見える場所として、記録や制作の過程を外部に開きます。

- 完成前のものも扱う。
- 試行錯誤や寄り道も活動の一部として残す。
- Contentを固い分類に押し込みすぎない。
- サイト自体を活動の中心にせず、活動をたどるための窓口とする。

## Relationship with esenus

esenusでは、つくる、試す、使う、記録する活動から、次の活動やアイデアにつながるInformationが生まれます。

`muse` は、その活動や記録を外部から見られる形にする場所のひとつです。ほかのAreaの機能や責務を取り込むことは目的としません。
